# Beyond Payment History

A seven-minute presentation, built as a single self-contained HTML file (no build step, works offline).

- `index.html`: the deck. Open it in a browser, or serve it with GitHub Pages.
- `beyond_payment_history_ted_final.html`: the same deck under its working filename.

## Presenting

The on-screen controls are hidden by default. Keyboard shortcuts:

| Key | Action |
| --- | --- |
| Right / Left arrow, Page Down / Page Up, Space | Next or previous slide or build step |
| Home / End | First or last slide |
| N | Presenter notes (Kim: slides 1–7, Julius: slides 8–14) |
| F | Fullscreen |
| T | Start or pause the seven-minute timer |
| H | Show or hide the presenter toolbar |

Slides 6, 9, 13 and 14 have a second step that appears on the next arrow press. The customer loan application form (the same questions as the prototype) and the bank dashboard are clickable during the demo.

## Notes

- Printing (Ctrl/Cmd + P) gives one slide or build step per page, plus a references page.
